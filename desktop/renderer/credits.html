GeoClock Offline

A local desktop adaptation of GeoClock Card. All application files, seasonal images, and timezone polygons are bundled. There is no online place search, automatic location lookup, telemetry, or automatic updater.

The clock uses this computer’s time. Settings are saved locally in the application profile. Copying the executable to another computer does not copy those settings.
