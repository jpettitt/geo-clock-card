GeoClock Screensaver for Mac

The same live world map you see at geoclock.world — day/night terminator, NASA imagery, your location markers and a ticking clock — as your Mac's screensaver. Free and open source, a companion to the GeoClock Wallpaper app.

Download from GitHub Releases

Grab GeoClockSaver.saver.zip from the newest release. Signed and notarized. Requires macOS 13 or later.

How it works

The screensaver doesn't render the map itself — it displays frames published by the GeoClock Wallpaper app and draws the live clock and marker overlay on top. So the app must be installed, running, and publishing frames (Settings → Map → “Publish frames for the GeoClock screensaver”). If you came here from the app's “Install screensaver…” button, that's already set up.

Install

  1. Download and unzip GeoClockSaver.saver.zip.
  2. Double-click GeoClockSaver.saver and confirm the install prompt (or copy it to ~/Library/Screen Savers/).
  3. Pick GeoClock under System Settings → Screen Saver → Other.

Don't have the wallpaper app yet? It's GeoClockWallpaper.zip in the same release.
